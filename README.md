# THESIA

This is a passion project that combines my hobbies of music and art into one.

## Create Mode

At its core, THESIA is a platform where users can draw on a canvas and play and listen to music generated from their artwork. Users can also type or paste an ASCII design, giving them the freedom to assign an instrument to each symbol in their design.

## Game Mode

For now, the only available game mode is **Musical Charades**, a multiplayer game supporting up to 10 players with no sign-up required. One player draws or types out a melody on the canvas, while the others try to guess the piece. Players are awarded points based on how quickly they can guess the title of the piece. The game is hosted through Render.

**Audio rendering:** MuseScore Basic SoundFont, provided by MuseScore.
